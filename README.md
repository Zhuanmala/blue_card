# 德国蓝卡资格自测与材料助手

一个纯静态 HTML 网站，用于帮助申请人快速自查德国 EU Blue Card 申请条件，并按结果生成材料准备清单。

## 功能

- 2026 年德国蓝卡薪资门槛判断
- 普通岗位、短缺岗位、毕业三年内、无学历 IT 经验路径分流
- 合同期限、学历认可、职业匹配、执业许可等风险提示
- 个性化材料清单
- 浏览器本地保存填写进度和材料勾选状态
- 打印结果，便于线下整理

## 部署

仓库包含 GitHub Pages Actions 工作流。推送到 `main` 后会自动发布静态页面。

## 信息来源

- Make it in Germany: EU Blue Card
- Bundesanzeiger: 2026 年蓝卡最低税前年薪公告
- German Missions in the United States: EU Blue Card checklist

本项目仅提供自测和准备辅助，不构成法律意见。
